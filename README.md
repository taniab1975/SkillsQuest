# SkillsQuest

A static starter project hub with left-hand navigation and a right-hand content window. All 17 sections requested by Tania are included; Main Ecosystem and Assessment have nested child sections. Program decisions remain open and are marked as drafts.

## Files
- `index.html`: shell and accessible navigation landmarks
- `styles.css`: responsive cream, sage and teal design
- `app.js`: section titles, starter prompts and hash-based navigation

Edit the `pages` array in `app.js` to develop the content. This version has no database, sign-in, student records, application submission or browser-local content editor.

Open `index.html` directly, or serve the folder using a static web server.

## Publication
Prepared locally. Not yet published. GitHub repository creation and public GitHub Pages publication need to be completed through the authorised account. The site must not claim SCSA endorsement or contain confidential learner data.
